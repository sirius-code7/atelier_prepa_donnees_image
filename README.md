# atelier prepa donnees images

Atelier de préparation d'un dataset d'images destiné à la classification des déchets.

## Objectif

Construire un jeu de données d'images propre et homogène avant son utilisation
pour un modèle de Machine Learning ou de Deep Learning.

## Classes

- cardboard
- glass
- metal
- paper
- plastic
- trash

## Structure

- `data/raw/` : dataset original
- `data/cleaned/` : dataset nettoyé
- `notebooks/` : notebook de travail
- `reports/` : rapports d'audit

## Préparation

L'atelier couvre notamment :

- l'exploration des images ;
- la détection des images problématiques ;
- l'analyse des résolutions ;
- l'analyse des canaux ;
- la détection des doublons ;
- l'analyse des classes ;
- le redimensionnement ;
- l'uniformisation RGB ;
- la normalisation des pixels ;
- le découpage train/validation/test ;
- la data augmentation.
